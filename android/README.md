# TeachFlow: Android prototype

Open this folder in Android Studio (Ladybug or newer) and build the APK: **Build → Build APK(s)**. Package `com.teachflow.agent`, minSdk 26, targetSdk 35, AGP 8.7, Kotlin 2.0, Compose BOM 2024.12.

- Source: `app/src/main/java/com/teachflow/agent/` (see `../docs/architecture.md`)
- Off-device logic check: `tools/logic-check/run.sh`
- Setup, permissions and usage: `../README.md`
